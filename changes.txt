Kurisu Security 2.1.0 - change summary
======================================

This file summarizes the 2.1.0 implementation. The repository was already on
MongoDB before this release; bot.txt and README now match the code.

LIVE COMMAND FIX
  - Added /premium activate as an alias for /premium enable.
  - /premium and /botprofile now defer their ephemeral reply before database,
    permission, download or logging work, preventing "Application did not
    respond" timeouts on slower hosts.
  - After pulling this change, run `npm run deploy` (or set AUTO_DEPLOY=true)
    so Discord receives the command schema. Adding a command in code does not
    register it by itself.

TASK A - ANTINUKE HARDENING
  - Hardened critical module defaults to ban:
    channelDelete, roleDelete, botAdd, permEscalation, automodRule,
    vanityChange, prune, massUnban, webhookDelete, nukeGuard, massBan, massKick.
  - Ban starts before mitigation and before any awaited persistence.
  - Punishment fallback: ban -> kick -> quarantine -> strip dangerous roles ->
    timeout.
  - Bot-add containment: ban/kick the added bot, remove integrations and
    dangerous roles, delete executor invites; trusted bots are skipped.
  - Hot-path in-memory caches for guild settings, modules, whitelist, watches
    and incident counts.
  - Concurrent punishment + mitigation, category-first restoration with at
    most 3 restore tasks at once.
  - Re-entrant per-executor locks and an already-punished set.
  - Persistent 24h watch survives a ban and restarts; watched rejoins/actions
    are banned.
  - Data migration removes only exact legacy default rows and preserves custom
    rows; idempotent via schema_migrations.
  - Optional compromised-account guard, default off, owner-only toggle.
  - Added/updated modules, punish, recovery, permissions and repository code.

TASK B - VERIFICATION PANEL
  - /verification panel <channel> [role], config, remove.
  - Public stable kv:verify panel; optional removal of the old panel.
  - Verified role creation/validation, dangerous-permission and hierarchy
    checks.
  - Ephemeral notices, 5s cooldown, raid/account-age gate, member log.
  - Mongo verification and verification_users collections/indexes.
  - Help category and command coverage.

TASK C - TICKETS
  - /ticket panel|setup|close|add|remove|claim|list.
  - Private ticket channels, atomic ticket numbering, max-open limit.
  - Confirmation close and delayed channel removal.
  - Transcripts off by default; when enabled, sent only to the ticket log
    channel and never stored in MongoDB.
  - Ticket log type; ticket_config and tickets collections/indexes.
  - Ticket channels excluded from antinuke snapshots, restoration and lockdown.
  - Manual deletion risk stated in the panel/setup UI.
  - Closing by number from another channel always targets the ticket channel,
    never the invoking channel.

TASK D - PREMIUM / GUILD PROFILE
  - Bot-owner-only /premium enable|disable|list.
  - Premium rows with expiry; lazy getPremium() expiry plus startup/hourly
    sweep resets the cosmetic guild-member profile.
  - /botprofile avatar|banner|reset|view for premium servers.
  - Uses guild.members.editMe() (guild-scoped, not global avatar).
  - PNG/JPEG/GIF/WebP validation with an 8 MB limit and magic-byte checks.
  - Stores only avatar/banner flags, never image data.
  - Read-only Premium line in Security Center.
  - No security, antinuke, raid or ticket feature is gated by premium.

TASK E - EMOJI / THEME SWEEP
  - Scanned src/ for Unicode emoji and replaced arrows/other symbols.
  - Registered the animated red ticket emoji
    <a:437007ticket:1571389266083188757> for ticket panels and ticket channels.
  - Regression tests enforce no Unicode emoji, raw embeds, accent colours or
    non-secondary buttons.
  - Consistent red-emoji, colourless Components V2 design.

DOCUMENTATION / VERSION
  - README.md rewritten for MongoDB, the new features and the current test
    suite.
  - bot.txt updated to 2.1.0 with current architecture, commands, database,
    rules and known limits.
  - package.json and package-lock.json bumped to 2.1.0.
  - .env.example already documents MongoDB; kept in sync.

TESTS
  - tests/kurisu.test.js converted to an async MongoDB suite using
    mongodb-memory-server.
  - 37 tests passing.
  - Remaining manual checks: live Discord commands, real audit-log delivery,
    emoji rendering, large-channel lockdown and recovery, hierarchy edge cases.

DO NOT COMMIT
  - .env, tokens, DATABASE_URL, MongoDB data files, SQLite files, the local zip.
